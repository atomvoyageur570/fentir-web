Téléphone Android

Installez l'application FENTIR sur votre téléphone.

Télécharger FENTIR Environ 45 Mo · gratuit
  1. Appuyez sur Télécharger FENTIR. Si un message dit que le fichier peut être dangereux, appuyez sur Télécharger quand même : c'est normal, l'appli n'est pas encore sur le Play Store.
  2. Une fois le téléchargement fini, ouvrez le fichier FENTIR.apk (dans la notification ou dans vos Téléchargements).
  3. Si le téléphone le demande, autorisez l'installation : Paramètres puis Autoriser cette source, puis revenez en arrière.
  4. Appuyez sur Installer. Si Play Protect affiche un avertissement, appuyez sur Plus de détails puis Installer quand même.
L'installation échoue ou l'appli ne s'ouvre pas ? Votre téléphone est peut-être plus ancien. Prenez cette version :

iPhone

Sur iPhone, FENTIR s'utilise depuis Safari et s'ajoute sur votre écran d'accueil, comme une vraie application.

Ouvrez cette page dans Safari. L'ajout à l'écran d'accueil ne fonctionne pas depuis WhatsApp ou un autre navigateur. Copiez le lien, puis collez-le dans Safari.

Dans WhatsApp, vous pouvez aussi appuyer sur l'icône boussole ou Ouvrir dans Safari en bas de l'écran.

Ouvrir FENTIR
  1. Appuyez sur Ouvrir FENTIR ci-dessus. L'application s'ouvre dans Safari.
  2. Appuyez sur le bouton Partager en bas de l'écran. Sur les iPhone récents, il est parfois dans le menu •••.
  3. Faites défiler et appuyez sur Sur l'écran d'accueil , puis sur Ajouter.
  4. L'icône FENTIR apparaît avec vos autres applis. Ouvrez-la désormais depuis votre écran d'accueil.
Ce qui change sur iPhone
  • Envoyer un colis fonctionne comme sur Android.
  • Pas de notifications : ouvrez l'appli pour voir où en est votre course.
  • Paiement : appuyez sur « Copier le code », puis collez-le dans l'appli Téléphone pour payer avec Orange Money.
  • Livrer est déconseillé pour l'instant : votre position n'est envoyée que lorsque l'appli est ouverte à l'écran.
